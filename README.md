# 🌸 Büşra - Full-Stack Developer Portfolio

Bu proje, modern web teknolojileri kullanılarak geliştirilmiş, "Pinterest estetiği" ve canlı pastel tonlarla (`#ffc3c9`) harmanlanmış kişisel bir portfolyo web sitesidir. 

Amacım; hem arka plan mimarilerindeki yetkinliğimi hem de son kullanıcının dokunduğu ön yüzdeki (UI/UX) estetik anlayışımı tek bir sayfada, akıcı animasyonlarla sergilemektir.

## ✨ Özellikler ve Tasarım Dili

*   **Pinterest Estetiği:** Yumuşak geçişler, cam efekti (glassmorphism), oval hatlar ve pastel renk paleti.
*   **Dinamik Animasyonlar:** Framer Motion ile sayfa kaydırma, hover efektleri ve organik çiçek/yaprak animasyonları.
*   **Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlarla %100 uyumlu akışkan ızgara (grid) yapısı.
*   **Kişiselleştirilmiş Bölümler:** 
    *   `Hero`: Göz alıcı ve dinamik giriş alanı.
    *   `Hakkımda`: Eğitim ve kurumsal staj deneyimlerimi içeren zaman tüneli.
    *   `Projeler`: Doğrudan GitHub repolarıma bağlanan etkileşimli proje kartları.
    *   `Yetenekler`: Sonsuz döngüde kayan teknoloji bandı.

## 🛠️ Kullanılan Teknolojiler

Bu proje, temiz kod prensiplerine sadık kalınarak aşağıdaki modern araçlarla inşa edilmiştir:

*   **Frontend:** React (Vite)
*   **Styling:** Tailwind CSS
*   **Animations:** Framer Motion
*   **Deployment:** Vercel 

## 🚀 Kurulum ve Çalıştırma

Projeyi kendi bilgisayarınızda yerel olarak çalıştırmak isterseniz aşağıdaki adımları izleyebilirsiniz:

1. Repoyu bilgisayarınıza klonlayın:
bash
   git clone [https://github.com/busramestan1/portfolio-website.git](https://github.com/busramestan1/portfolio-website.git)
Proje dizinine gidin:

Bash
   cd portfolio-website
Gerekli bağımlılıkları (paketleri) yükleyin:

Bash
   npm install
Geliştirme sunucusunu başlatın:

Bash
   npm run dev
